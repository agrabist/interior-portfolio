КАК ОТКРЫТЬ САЙТ

1. Откройте папку C:\Users\agrab\Desktop\codex в Проводнике.
2. Дважды нажмите на index.html. Сайт откроется в браузере.
3. Если Windows предложит выбрать программу, выберите Chrome, Edge или Firefox.

Установка программ, сборка и запуск сервера не нужны.
Сайт работает без интернета: изображения локальные, шрифты системные.
Сайт не опубликован: все файлы находятся на вашем компьютере.

ФАЙЛЫ
index.html — тексты и структура сайта.
styles.css — цвета, размеры, внешний вид и адаптация для телефонов.
script.js — меню, фильтры проектов и галерея.

Название FORMA, тексты проектов, площади и адрес hello@forma.example — примеры.
Перед реальным использованием замените их своими данными.
Вместо фотографий пока показаны локальные SVG-заглушки. Как добавить свои фотографии — ниже.
Контактная ссылка открывает почтовую программу; отправки сообщений с сайта нет.

ГАЛЕРЕЯ
Нажмите на проект. Перелистывайте стрелками, миниатюрами или клавишами ← и →.
На телефоне можно провести пальцем по фото. Закрыть: крестик или Escape.

ЛОКАЛЬНЫЕ ФОТОГРАФИИ

assets/images/hero.svg — главный экран.
assets/images/studio.svg — раздел «О студии».
assets/images/project-1/01.svg … 03.svg — «Мягкая геометрия».
assets/images/project-2/01.svg … 03.svg — «Ближе к природе».
assets/images/project-3/01.svg … 03.svg — «Городская пауза».
assets/images/project-4/01.svg … 03.svg — «Естественный ритм».
assets/images/placeholder.svg — запасная заглушка для недоступных изображений.

Сохраните фотографии в соответствующие папки в формате JPG, WebP или PNG.
Например, assets/images/project-1/01.jpg. Не переименовывайте JPG в SVG.
В script.js замените соответствующее имя в массиве photos на project-1/01.jpg.
Для обложки проекта также обновите src изображения в index.html.
Для главного экрана и студии замените пути hero.svg и studio.svg в index.html.
Остальные фотографии галереи и миниатюры используют одни и те же пути в script.js.
Рекомендуемая ширина фотографий — 1600–2400 пикселей; сжимайте файлы перед добавлением.
Если фотография отсутствует или повреждена, JavaScript покажет запасную заглушку.
До добавления реальных фотографий описания изображений относятся к будущим интерьерам.

Системные шрифты: Segoe UI / Helvetica Neue / Arial для текста,
Avenir Next / Avenir / Segoe UI для заголовков; Georgia для курсива.
Конкретный шрифт зависит от операционной системы. Загрузки шрифтов из интернета нет.

ЛОКАЛЬНАЯ ПРОВЕРКА

Из папки проекта: python3 -m http.server 8000 --bind 127.0.0.1
Сборка и установка зависимостей не требуются. Проверка синтаксиса: node --check script.js.
Перед сохранением в GitHub проверьте git diff и добавьте assets/images вместе с изменениями сайта.
